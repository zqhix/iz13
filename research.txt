БЛОК 1

Тема:
Приложение для определения цветов на определенном фрагменте фото с помощью камеры.

1. Цель программного продукта

Создание приложения для определения цвета выбранного участка изображения.

2. Основные задачи

- получение изображения с камеры;
- выделение области изображения;
- анализ цветов;
- отображение результата;
- сохранение результатов.

3. Анализ существующих решений

1. Color Grab
2. Color Picker
3. Pixolor

4. Характеристики качества

- точность определения цвета;
- скорость работы;
- удобство интерфейса;
- поддержка RGB/HEX;
- работа с камерой.

5. Конкурентные преимущества

- простой интерфейс;
- высокая скорость;
- низкое потребление ресурсов;
- работа в реальном времени.

6. Жизненный цикл процесса

- запуск приложения;
- получение изображения;
- выделение области;
- анализ;
- вывод результата.

7. Диаграмма IDEF0

A0 — Определение цвета изображения

Вход:
изображение.

Выход:
цвет и RGB код.

8. Пользователи системы

- дизайнер;
- разработчик;
- художник;
- обычный пользователь.
